# Job Application Tracker

転職活動における求人応募・選考状況・面接履歴を一元管理するためのWebアプリケーションです。

複数の求人サイトから応募していると、

- どの企業に応募したのか
- いつ応募したのか
- どの求人に応募したのか
- 面接を受けたか
- 選考結果はどうだったか
- 過去に同じ企業へ応募したことがあるか

などの情報が分かりにくくなるため、それらをまとめて管理できるアプリを目指しています。

---

## アプリ名

**Job Application Tracker**

---

## 開発目的

転職活動中の応募履歴を記録し、過去の応募状況を簡単に確認できるようにすることを目的としています。

特に、過去に応募した企業へ再度応募しようとした場合に、以前の応募履歴を確認できる機能を主要機能として実装する予定です。

---

## 主な機能

### 応募情報管理

以下の情報を登録・管理できるようにします。

- 会社名
- 求人タイトル
- 求人URL
- 求人サイト
- 勤務地
- 給与
- 雇用形態
- 応募日
- 応募方法
- 選考ステータス
- メモ

### 選考ステータス管理

応募後の選考状況を管理できるようにします。

例：

- 応募済み
- 書類選考中
- 書類選考通過
- 面接予定
- 面接完了
- 内定
- 不採用
- 辞退

### 面接履歴管理

1つの応募に対して複数の面接履歴を保存できるようにします。

- 面接日
- 面接段階
- 面接形式
- 質問内容
- 回答内容
- 面接後のメモ
- 面接結果

### 不採用理由管理

不採用になった場合、その理由と詳細メモを記録できるようにします。

### 過去応募チェック

会社名をもとに過去の応募履歴を検索し、以前応募した可能性がある企業の場合は警告を表示します。

会社名の表記ゆれについても可能な範囲で対応する予定です。

例：

- 株式会社ABC
- ABC株式会社
- （株）ABC

過去応募が存在しても、再応募は禁止しません。

### 求人情報コピー＆ペースト

Indeedなどの求人サイトからコピーした求人情報を貼り付け、求人情報の原文を保存できるようにします。

さらに、貼り付けた文章から以下の情報を可能な範囲で自動抽出し、応募フォームへ反映する機能を実装する予定です。

- 会社名
- 求人タイトル
- 勤務地
- 給与
- 雇用形態
- 求人サイト
- 求人URL

自動抽出された情報は、保存前にユーザーが確認・修正できるようにします。

### 検索・絞り込み

以下の条件で応募履歴を検索できるようにします。

- 会社名
- 求人タイトル
- 応募日
- 求人サイト
- 選考ステータス
- 選考結果

### Dashboard

転職活動全体の状況を確認できるDashboardを実装する予定です。

表示予定：

- 総応募数
- 今月の応募数
- 選考中
- 面接予定
- 不採用
- 内定
